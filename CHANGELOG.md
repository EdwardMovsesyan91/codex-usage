# Changelog

## 0.1.0 — Initial release candidate

- Separate 5-hour and weekly status bar items showing remaining Codex quota.
- Ten-character progress bars with theme-based warning and error severity.
- Markdown tooltips with usage, reset times, countdowns, and last update time.
- Refresh and Show Details commands.
- Direct Codex app-server stdio integration, live notifications, and conservative fallback refresh.
- Privacy-filtered diagnostics in the Codex Usage output channel.
